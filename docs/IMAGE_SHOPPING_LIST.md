The build environment cannot reach Unsplash, Pexels or Pixabay (see docs/IMAGE_SLOTS.md and the 9B-1 report), so the files have to be downloaded manually. **138 files = 137 photos + 1 video** (customer photos were replaced by initials avatars). Save every file with the **exact filename** shown, into the git-ignored folder `assets-incoming/` at the project root.

Allowing these hosts in the environment's network settings would let the next step source and download the files itself; otherwise use this list.

## How to download
1. Open the site (Unsplash, Pexels or Pixabay), search the terms, open the photo's own page and **read its licence text** (do not assume). Skip photos with a visible brand logo, an identifiable person (unless the licence clearly allows commercial use) or "Unsplash+" / premium-only content.
2. Download the **original / largest size** (not "small"). Orientation and minimum size are in the table; if a photo is bigger it is fine.
3. Save it as the filename in the last column, e.g. `assets-incoming/product-01-main.jpg` (PNG/WebP are fine too: keep the base name, change the extension).
4. For every file add one line to `assets-incoming/SOURCES.csv` (create it with this header) — this becomes `images.json` / `CREDITS.md` later:

```
filename,source_site,photo_page_url,author_name,author_profile_url,license_name,license_page_url,date_checked
product-01-main.jpg,Pexels,https://www.pexels.com/photo/...,Jane Doe,https://www.pexels.com/@janedoe,Pexels License,https://www.pexels.com/license/,2026-10-14
```

Tips: use the search terms in English; "4:5" means portrait (taller than wide); keep the subject near the centre (the site crops differently on phone and desktop); for product shots a plain background and soft daylight look best; avoid text, watermarks and heavy filters. A consistent look across the 25 products matters more than perfection — pick one palette (cream/neutral for women's, dark slate for men's).
